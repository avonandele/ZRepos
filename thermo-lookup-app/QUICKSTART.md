# Quick Start Guide

## The app is ready to use - no setup required!

All thermodynamic data is embedded directly in the HTML file.

### How to Use

**Step 1:** Download `index.html` from the repository
**Step 2:** Double-click to open in your web browser
**Step 3:** Start looking up properties immediately!

**That's it!** No uploads, no server, no installation needed.

## Pre-Loaded Data

The app includes 18 complete thermodynamic property tables:

**Water (5 tables)**
- Saturated water by temperature and pressure
- Superheated water, compressed water
- Saturated ice-water vapor

**R-134a (3 tables)**
- Saturated R-134a by temperature and pressure
- Superheated R-134a

**Ideal Gases (10 tables)**
- Air, Nitrogen, Oxygen, Carbon Dioxide, Carbon Monoxide
- Hydrogen, Water Vapor, and more

## Try It Now

### Example: Saturated Water at 50°C

1. Select Material: **Water**
2. Select Table: **A-4 T Saturated Water**
3. Choose Unit System: **Metric (SI)**
4. Known Property: **T (°C)**
5. Value: **50**
6. Find Property: **Enthalpy (h)**
7. Click **Calculate**

You should see interpolated values for hf, hfg, and hg at exactly 50°C!

## Features

- **Metric & English Units**: Switch between SI and IP units anytime
- **Smart Interpolation**: Linear interpolation with extrapolation warnings
- **Multiple Properties**: Get all related values (e.g., hf, hg, hfg) at once
- **Works Offline**: No internet connection required
- **Fast**: Instant property lookups

## Troubleshooting

**App not loading?**
- Make sure you're using a modern browser (Chrome, Firefox, Safari, Edge)
- The file is 325KB - wait for it to fully download and load

**Data not showing?**
- All 18 tables are embedded - no uploads needed!
- Just select your material and table to get started

**Wrong results?**
- Check you're using the correct unit system (Metric vs English)
- Verify your input value is reasonable for the property

**Need to add custom data?**
- Use "Upload Different Files" link in the app
- Upload your own CSV files if you need additional tables
